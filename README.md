# 💻 装机小站（PC Build Guide）

帮助零基础用户**认识电脑配件、学会装机、自己搭配配置单**的中文学习网站。

在线预览：`npm start` 后访问 <http://127.0.0.1:3000>

## ✨ 功能

- **配件认识**：九大配件（CPU/显卡/主板/内存/硬盘/电源/机箱/散热/显示器）的作用、参数、选购建议，大白话讲解
- **装机教程**：十步图文教程，每步带安全提示与避坑说明
- **互动配置单**：像「我的世界装模组」一样选配件——**不兼容的选项自动置灰禁用**（插座平台 / 内存代数 / 机箱限位 / 电源功率全检查），含 38 张显卡、从 99 元亮机卡到 RTX 5090
- **深色 / 浅色主题**、移动端适配、配置单本地保存

## 🚀 快速开始

```bash
npm install     # 无需安装任何依赖（零依赖项目，可跳过）
npm start       # 启动服务器，打开 http://127.0.0.1:3000
```

修改配件数据：编辑 `data/parts.json` → `npm run sync-data` → 刷新页面。

## 📦 部署到互联网

网站支持纯静态部署（Vercel / Cloudflare Pages / GitHub Pages 均免费），
搜索引擎收录（百度 / Google / Bing）与 SEO 策略请阅读 **[docs/部署指南.md](docs/部署指南.md)**。

## 📁 目录结构

- `public/` —— 全部前端资源（**部署只需此目录**）
- `server.js` —— 本地开发用的 Node 零依赖服务器 + `/api/parts` 数据接口
- `data/parts.json` —— 配件教学与商品数据（单一数据源）
- `scripts/sync-data.js` —— 数据离线副本同步
- `docs/部署指南.md` —— 部署与 SEO 指南

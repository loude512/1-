🛠️ 装机实战十步

把一堆零件变成一台完整的电脑。按顺序操作，每一步都标出了要点与注意事项。开始前建议先读一遍全部步骤，心里有谱再动手。

📋 一页纸装机 checklist（点击展开）
  1. 防静电 + 工具 + 配件清点（螺丝刀、硅脂、扎带）
  2. 机箱外：CPU → 内存 → M.2 → 散热器（依次装到主板上）
  3. CPU 三角标记对准；内存插 2/4 槽；M.2 斜插拧螺丝
  4. 散热器涂黄豆大小硅脂；撕膜（别忘了！）
  5. 电源装机箱；主板对铜柱装进去；I/O 挡板先装
  6. 显卡插 PCIe x16，扣挡板、接供电
  7. 接面板跳线（开机键线先接，风扇线后接）
  8. 理线：扎带松紧适度，避开风道
  9. 通电：先插显示器线再按开机键，看 BIOS 是否点亮
  10. 装系统（U 盘启动盘）、装驱动、跑温度测试

🎉 点亮之后还要做什么？

硬件完成只是开始，这几步让电脑真正“能用”

1️⃣ 进入 BIOS 检查

开机狂按 Del / F2 进入 BIOS，确认 CPU、内存容量与频率、硬盘都被正确识别。开启 XMP / EXPO 让内存跑到标称频率。

2️⃣ 安装 Windows 系统

用另一台电脑制作 U 盘启动盘（微软官方工具即可），插上后从 U 盘启动安装。系统装在速度最快的 NVMe 固态上。

3️⃣ 装驱动与测试

先装主板芯片组驱动，再装 NVIDIA / AMD 显卡驱动。跑 15 分钟游戏或压力测试，观察 CPU / 显卡温度是否正常（一般 80°C 内放心用）。

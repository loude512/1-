📖 配置单怎么读？

关于这里的检查规则与技术细节

🚫 不兼容会怎样？

像「我的世界」装模组一样：已选配件会实时对剩余选项做体检，冲突的商品直接置灰、无法点选，并用大白话告诉你原因（如「这块主板是 AMD 专用的，Intel CPU 装不进去」）。红色代表物理上装不进去，黄色代表能装但不建议。配件按阵营 / 世代 / 类型自动分组，默认收起，点一下即可展开挑选。

✔️ 检查哪些内容？

  • CPU 与主板插槽是否一致（LGA1200 / LGA1700 / AM4 / AM5）
  • 内存代数与主板是否匹配（DDR4 / DDR5）
  • 机箱能否装下主板版型、显卡长度、散热器高度或水冷冷排
  • 散热器扣具是否支持 CPU 插槽、压制力是否够
  • 电源功率是否满足整机功耗 × 1.5 的余量
  • 无核显 CPU 是否配了显卡、矿卡（P106）是否有核显输出

💡 功耗怎么算的？

整机参考功耗 = CPU TDP + 显卡 TDP + 其他配件约 60W（主板 / 内存 / 硬盘 / 风扇）。建议电源功率 = 参考功耗 × 1.5（电源留有余量更安静、更稳定，且适合后续升级）。实际功耗会随负载变化，高端显卡瞬时功耗可能超过标称 TDP——所以选大不选小。

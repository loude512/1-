新手常见问题 ❓

每个装机新人都曾纠结过这些

我完全没有基础，真的能学会装机吗？

能。装电脑常被形容为“成年人版的乐高积木”：配件的接口都有防呆设计，插错几乎插不进去。只要按顺序操作、注意插头方向与螺丝力度，一个下午就能完成。本站的教程就是为零基础新手设计的。

装机最怕出错，最需要注意什么？

① 防静电：装前洗手或摸一下金属水龙头/机箱，别穿毛衣在干燥地毯上操作；② CPU 对准三角形标记，放下拉杆即可，绝不硬按针脚；③ 先在机箱外把 CPU、内存、M.2 硬盘、散热器装到主板上，再整体装入机箱，会顺手得多；④ 通电前检查所有供电线是否插紧。

怎么知道配件之间兼不兼容？

三个最容易翻车的地方：CPU 与主板的插槽必须一致（LGA1700 / AM5）；内存的代数必须与主板一致（DDR4 / DDR5）；显卡长度、散热器高度、冷排尺寸必须在机箱限位之内。本站“配置单”页会自动为你检查这些。

电源功率怎么选？是不是越大越费电？

不是。电脑实际功耗由配件决定，电源标的只是“最大能提供多少”。额定功率留有余量反而更安静、更稳定。经验法：CPU + 显卡 TDP 之和乘 1.5–2 倍即可。例如 i5-13400F（65W）+ RTX 4060（115W）≈ 180W × 1.5 ≈ 650W 电源很合适。

装完硬件就结束了吗？

硬件装完只是第一步。还需要：开机进入 BIOS 确认硬件识别 → 用 U 盘安装 Windows 系统 → 装好显卡驱动与主板芯片组驱动。系统装好后，建议跑一会儿压力测试观察温度，确认散热没问题。

预算有限，哪些配件可以省，哪些不能省？

不能省：电源（劣质电源可能毁掉整台电脑）、主板（决定稳定性与扩展）、散热（保护 CPU）。可以先省：机箱外观、RGB 灯效、高频内存、顶级固态。另外，显示器、键盘鼠标这些外设对体验影响很大，值得留一部分预算，别全砸在主机里。

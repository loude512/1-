# 🚀 装机小站 · 部署与搜索引擎收录指南

本文档手把手教你把这个网站发布到互联网上（免费），并提交给搜索引擎收录。

---

## 一、原理：为什么现在就能部署

本网站由两部分组成：

- `public/` 目录 —— **全部前端页面**（HTML / CSS / JS）
- `server.js` —— 本地开发用的 Node 服务器，顺带提供 `/api/parts` 数据接口

`public/js/parts-data.js` 是配件数据的**离线副本**：即使部署到没有后端的纯静态托管平台，
网站也能完整运行。**部署时只需要把 `public/` 整个文件夹传上去即可。**

> 修改配件数据后，先编辑 `data/parts.json`，然后运行 `npm run sync-data` 同步到离线副本，再重新部署。

## 二、部署：三个免费方案（任选其一）

### 方案 A：Vercel（最推荐 · 零配置 · 全球 CDN）

1. 注册 [GitHub](https://github.com)（全球最大代码托管，免费）
2. 注册 [Vercel](https://vercel.com)（建议直接用 GitHub 账号登录）
3. 把整个项目上传到 GitHub：
   - 新建仓库（New repository），起名如 `pc-build-guide`
   - 可以上传压缩包、用 GitHub Desktop，或命令行：
     ```bash
     cd E:\zcode\3
     git init
     git add .
     git commit -m "装机小站"
     git branch -M main
     git remote add origin https://github.com/你的用户名/pc-build-guide.git
     git push -u origin main
     ```
4. 在 Vercel 点 **New Project → Import** 你的仓库：
   - Framework Preset：**Other**
   - Build Command：留空（不用填）
   - **Output Directory：填 `public`**
   - 点 **Deploy**，等 30 秒左右
5. 完成 🎉 你会得到一个免费域名，类似 `pc-build-guide.vercel.app`，**全球可直接访问**

### 方案 B：Cloudflare Pages（国内访问相对稳定）

1. 注册 [Cloudflare](https://dash.cloudflare.com/sign-up)
2. 左侧 **Workers & Pages → Create application → Pages → Upload assets** 或连接 GitHub
3. 部署目录选 **`public`**，构建命令留空
4. 得到 `xxx.pages.dev` 域名，国内访问通常比 Vercel 顺畅一点

### 方案 C：GitHub Pages（最简单，但国内访问较慢）

1. 把项目传到 GitHub（同方案 A 第 3 步）
2. 仓库 **Settings → Pages**：
   - Source：**Deploy from a branch**
   - Branch：`main`，文件夹选 **`/public`**，保存
3. 等几分钟，得到 `https://你的用户名.github.io/仓库名/`
4. 注意：GitHub Pages 的默认 URL 带目录前缀，部署后页面内的绝对路径（如 `/css/style.css`）
   需要保持仓库根目录就是域名根。若出现样式丢失，改用方案 A / B。

## 三、域名：要不要买自己的域名？

- 部署平台送的域名（`xxx.vercel.app` 等）**永久免费**，直接能用
- 想要 `www.你的名字.com`：
  - 在阿里云 / 腾讯云买域名（`.com` 约 ¥60/年）
  - 在部署平台 **Settings → Domains** 添加域名，按提示去域名商解析 DNS 即可
  - `example.com` 不用备案也能解析到境外服务器（下条说明）

### ⚠️ 关于「ICP 备案」（重要，看你的受众）

| 托管位置 | 是否需要备案 | 国内访问 | 百度收录 |
|---|---|---|---|
| Vercel / Cloudflare / GitHub（境外） | ❌ 不需要 | 速度看运气，多数能开 | 较慢甚至可能不收录 |
| 阿里云 / 腾讯云等**大陆服务器** | ✅ 必须备案（1–3 周） | 秒开 | 明显更友好 |

**结论**：只想让朋友 / 网友快速看到 → 用境外免费托管；想认真做百度 SEO、服务国内访客 →
买大陆服务器 + 域名备案（学生服务器有优惠，如阿里云轻量应用服务器）。

## 四、提交搜索引擎收录（部署后必做）

### 1. 百度（ziyuan.baidu.com）

1. 登录 [百度搜索资源平台](https://ziyuan.baidu.com)
2. **用户中心 → 添加网站** → 填你的域名 → 完成验证（下载验证文件放到 `public/` 根目录重新部署，或用 DNS 验证）
3. **普通收录 → 提交 sitemap** → 填 `https://你的域名/sitemap.xml`
4. 百度对新站收录较慢（几天到几周），若用的是境外服务器会更慢 —— 保持耐心，或坚持手动提交新页面

### 2. Google（search.google.com/search-console）

1. 打开 [Google Search Console](https://search.google.com/search-console)
2. 添加资源 → 验证（同上）
3. **站点地图 → 提交 `sitemap.xml`**，通常 1–2 天开始收录

### 3. 必应（bing.com/webmasters）

- [Bing Webmaster Tools](https://www.bing.com/webmasters) 流程相同，提交 sitemap 即可

## 五、SEO 的真话：怎么让搜索排名靠前

先泼盆冷水：**搜索「电脑」直接置顶，新站几乎不可能**。这种超热词的首页常年是京东、
中关村在线、太平洋电脑网等积累了十几年权重的大站。任何人告诉你「交钱就能置顶」的，
都是竞价广告（SEM）或骗子。

但**长尾关键词**（更具体、竞争小的搜索词）是新站的机会，而这正是本站天生擅长的内容：

| 现实策略 | 对应本站优势 |
|---|---|
| 主攻长尾：「电脑小白装机教程」「显卡怎么选」「装机配置单兼容性检查」 | 每页标题/描述已埋好这些词 |
| 原创且真正有用的内容 | 互动配置单是全网稀缺功能 |
| 页面打开速度极快（纯静态） | 搜索引擎加分项 |
| 移动端适配 | 网站本身就是响应式 |
| 持续更新（新配件、新教程） | 改 `data/parts.json` 后 `npm run sync-data` 重新部署 |

**能做的事**：
1. 内容持续更新：新显卡上市、新装机知识、常见故障排查都写成页面，每个页面聚焦一个长尾词
2. 去有人的地方分享：贴吧「装机吧」、知乎、B 站评论区、QQ 装机群，带上链接（既能帮人也能引流）
3. 和其它个人站交换友情链接
4. 每次更新后到搜索资源平台手动提交新 URL
5. 保持耐心：SEO 一般 3–6 个月起效

**不能做的事（会被惩罚）**：关键词堆砌、隐藏文字、买垃圾外链。

## 六、日常维护流程

```bash
# 1. 本地修改数据
#    编辑 data/parts.json
npm run sync-data        # 同步到 public/js/parts-data.js

# 2. 本地预览
npm start                # 打开 http://127.0.0.1:3000

# 3. 重新部署
git add . && git commit -m "更新配件" && git push
# Vercel / Cloudflare 会自动拉取并重新部署
```
